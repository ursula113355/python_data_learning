# Airbnb Price analysis

## Goal
- Airbnb listing price and factors affecting price.

## Dataset
- Boston Airbnb Open Data from Kaggle(listings dataset)

## Tools
- Python
- Pandas
- Matplotlib

## Analysis
- Price distribution
- Average price by room type
- Price distribution by room type
- Average price by area

## Key Findings
- Entire homes/apt are more expensive than private rooms and shared rooms
- Some areas have significantly higher average prices
- Most listing fall within a moderate price range
